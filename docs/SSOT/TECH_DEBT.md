## How to add a new TD

1. Pick the next free ID above the highest ever used (check this file **and** `archive/TECH_DEBT-history.md`).
2. Add a row under the right Active section with severity, item, and closing slice.
3. If the TD is blocking the current feature, also link it from the relevant `spec/{domain}.md` AC when the feature ships.
4. When closing: mark it ✅ with the closing PR/migration, then move the row to [`archive/TECH_DEBT-history.md`](./archive/TECH_DEBT-history.md) under its area. Never delete it.
